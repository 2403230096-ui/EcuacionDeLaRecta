# README – Calculadora de la Función Lineal

## Descripción

Este programa en Python calcula los valores de una función lineal con la fórmula:

y=mx+by = mx + by=mx+b

El usuario ingresa la pendiente (`m`), la ordenada al origen (`b`) y el valor límite de `x`. El programa genera una tabla con los valores de `x` y su correspondiente `y`.

## Requisitos

- Python 3.x

## Uso

1. Ejecuta el programa.

2. Ingresa los valores de `m`, `b` y el límite de `x`.

3. Se mostrará una tabla con los resultados.

### Ejemplo

Entrada:

```
Ingresa el valor de m: 2
Ingresa el valor de b: 3
Ingresa el valor limite: 5
```

Salida:

```
x: 1 | y: 5
x: 2 | y: 7
x: 3 | y: 9
x: 4 | y: 11
x: 5 | y: 13
```

## Fórmula utilizada

y=(m×x)+by=(m\times x)+by=(m×x)+b
